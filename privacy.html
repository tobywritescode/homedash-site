Privacy

Last updated 30 October 2026

homeDash is a private dashboard used by one family. Only members of that household sign in to it.

What it accesses

With permission, homeDash reads Google Calendar events from calendars belonging to, or shared with, the family's own Google account, so they can be shown on the kitchen screen. If enabled, it may also create or edit events on those calendars when a family member asks it to.

Where the data goes

Calendar data is fetched directly from Google to a device in the family's home and shown on a screen there. It is not sold, shared, or sent to any third party, and it is not used for advertising or analytics. Short-lived copies are kept in memory on that device only to keep the screen up to date.

Google API data

homeDash's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from your Google Account permissions.

Contact

Questions can be raised through this site's GitHub issues.
